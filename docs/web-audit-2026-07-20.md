## Pending — Sprint 2 (performance)

Measured today: TTFB 300-400 ms landing / 466-973 ms blog (all pages dynamic,
no CDN cache); ~893 KB landing transfer. Targets and fixes:

1. **Static/ISR everywhere**: add `setRequestLocale(locale)` (next-intl) to
   `[locale]/layout.tsx` + pages; remove the disabled waitlist `cookies()` gate
   from the landing; `generateStaticParams` + `revalidate` on blog/SEO pages.
2. **Middleware**: only call `supabase.auth.getUser()` for /dashboard, /perfil,
   /auth paths; migrate deprecated `middleware` file convention to `proxy`.
3. **Material Symbols 1.1 MB render-blocking font** → self-hosted ~20 KB subset
   (`icon_names` param) or inline SVGs (lucide-react already installed, unused).
4. **Textures**: 193 KB PNG hotlinked from lh3.googleusercontent.com in
   `globals.css` + 198 KB `adventure-pack-bg.png` + transparenttextures.com
   tiles in HowItWorks/CollectionOffer → self-hosted small WebP tiles.
5. **Hero**: preloaded twice (2 art-direction variants both `priority`), source
   only 442px shown at 540×675 (blurry) → single responsive Image ≥1200px.
6. **BookCollection** fetches client-side (2 sequential uncached requests) →
   server-fetch with revalidate, pass as props.
7. **i18n payload**: full 85 KB catalog serialized into every page → `pick`
   client-needed namespaces.
8. **LCP anomaly**: landing emits NO LCP metric in Chrome (webfont interplay) —
   PSI/CrUX can't score it. Investigate after font changes.
9. Add `@vercel/speed-insights` + `@vercel/analytics` (branch exists:
   `vercel/vercel-web-analytics-to-nextjs-j6jalg`).
