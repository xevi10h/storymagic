## Image model decision
Winner among tested: **`gpt-image-2.5-sunburst`** (OpenAI, `/v1/images/edits`, up to 16 refs, sizes multiple of 16 up to 3840).
- Final: quality `high`, 2432² pages (200 mm + bleed @300 dpi), 3840×1920 spreads. ~$1.75/book, ~60 s/img, all parallel. Consistency 9/10, beauty 8.5/10.
- Preview: `gpt-image-2.5-flare` medium (~$0.025/img, ~16 s).
- Recipe: one multi-pose character sheet (front/¾/profile/back + expressions + companions) generated first; every scene = `[sheet, photo?]` refs, role preamble, negative cast for absent companions, explicit scale for wide shots, only present characters described, style suffix. Sheet-only beats sequential chaining.
- Untested (no billing/credits): Nano Banana Pro / 2, Seedream 4.5/5, Kling O3, FLUX.2 flex baseline.
- Gaps: digital (not analog) watercolor feel; minor detail drift (curl density, buttons); spreads ~237 dpi → light upscale.

## P0 — before any launch
1. Portrait/generation outage: no provider fallback, raw provider errors shown to parents, failure wipes the parent's input (localStorage cleared, "Volver" → empty form).
2. Prompt cap: 1000-char `MAX_FLUX_PROMPT_LENGTH` + consistency lock leaves 48–79 chars for the scene → images lose action/setting (`scene-screenplay.ts:248-265`).
3. `/complete` (~875 s) can't finish in `maxDuration=300`; cron re-runs regenerating all 12 scenes each time → $50–90/order, never delivered. Needs durable per-scene jobs.

5. Print: ~125 dpi pages / ~88 dpi spreads (<150 min); cover never regenerated in final; `snap32` squashes aspect.
6. Cover geometry: Gelato fields renamed → width 0; pages stretched ~9% vertically on the one delivered order.
7. Page parity: images face the next scene's text; panoramas split across a sheet.
8. Guest buyers get no confirmation email (webhook reads auth email, not `customer_details.email`); digital orders no email.
9. Misleading claims: "cosido al hilo", "Munken 170 g", "hecho a mano", "ejemplar numerado" vs glued Gelato silk + extra-copy upsell; "3 libros -20%" not implemented; Pack Aventura (+12,90 €) sold but never fulfilled + fake "Más popular" badge.

## Target architecture
1. Immutable Character Bible JSON → one identity string (never the name as visual cue).
2. Character sheet rendered once with the final model, in background while the parent builds the path.
3. One structured Book Plan (full manuscript + shot spec per scene) from one strong LLM call; text and images from the same object. Dedication verbatim.
4. Deterministic prompt assembly, no truncation.
5. Durable idempotent per-scene jobs, versioned storage paths, typed provider errors + ops alert.
6. QA against sheet + scene text; repair with edit model.
7. Teaser preview: cover + scene 1 in ~10–15 s, rest streams.
8. Final: 12 scenes + new cover at print res → QA → PDF (correct parity + real Gelato cover geometry) → validation gate → separate Gelato submit → emails.
